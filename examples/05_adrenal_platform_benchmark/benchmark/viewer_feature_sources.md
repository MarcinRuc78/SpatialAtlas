# Sources for the viewer feature matrix

Accessed 21 July 2026. Features were classified from current official documentation and the reproducible evidence retained with this benchmark; related but non-equivalent functions are qualified explicitly.

- SpatialAtlas: version 1.0.0 source code, example protocols and benchmark records in this repository.
- Vitessce: https://vitessce.io/docs/ and https://vitessce.io/docs/data-file-types/
- CELLxGENE Annotate: https://github.com/chanzuckerberg/cellxgene
- TissUUmaps AnnData: https://tissuumaps.github.io/TissUUmaps-docs/docs/advanced/anndata.html
- TissUUmaps Docker: https://tissuumaps.github.io/TissUUmaps-docs/docs/sharing/docker.html
- Single-cell Spatial Explorer: https://doi.org/10.1186/s12859-023-05150-1
- Loupe Browser: https://www.10xgenomics.com/support/software/loupe-browser/latest
- Loupe Browser Visium HD co-expression tutorial: https://www.10xgenomics.com/support/software/loupe-browser/latest/tutorials/lb-hd-spatial-gene-expression

Terms such as “multi-gene” are not treated as equivalent across tools: a four-channel raw-expression composite, two-list co-expression, multiple marker layers, coordinated feature views, and a precomputed signature are reported separately.
